# Collers - Modern Sneaker Collection Landing Page 🚀

A sleek and responsive landing page for a sneaker collection website, built with modern web technologies. This project showcases a beautiful UI design with interactive elements and smooth animations.

![Landing Page Preview](assets/Picture.png)

## 🎯 Features

- Modern and responsive design
- Interactive product showcases
- Beautiful gradient backgrounds
- Shopping cart functionality
- Newsletter subscription
- Product collection display
- Event showcase section

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure and content |
| CSS3 | Styling and animations |
| Tailwind CSS | Utility-first CSS framework |
| JavaScript | Interactivity and dynamic content |
| Google Fonts | Typography and icons |

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone [your-repo-link]
   ```

2. **Open the project**
   - Navigate to the project directory
   - Open `index.html` in your browser
   
   > **Note**: Internet connection is required for Tailwind CSS CDN
